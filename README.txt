ТК 412 — расписание (PWA)

Файлы: index.html, manifest.webmanifest, sw.js, иконки *.png. Все лежат в одной папке.

ВЫЛОЖИТЬ (любой из вариантов, оба бесплатные, оба по https):
1) Cloudflare Pages: dash.cloudflare.com -> Workers & Pages -> Create -> Pages ->
   Upload assets -> загрузите содержимое этой папки (или zip) -> Deploy.
   Получите адрес вида https://имя.pages.dev
2) GitHub Pages: создайте репозиторий, загрузите файлы в корень,
   Settings -> Pages -> Deploy from branch -> main / root.

УСТАНОВИТЬ НА ТЕЛЕФОН:
Android (Chrome): откройте адрес -> меню ⋮ -> «Установить приложение» (или «Добавить на гл. экран»).
iPhone (Safari): откройте адрес -> «Поделиться» -> «На экран Домой».
